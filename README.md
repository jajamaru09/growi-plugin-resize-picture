# growi-plugin-resize-picture

GROWI の画像の表示幅を、画像の直後に書く HTML コメント `<!--NN%-->` で指定できるようにするプラグインです。編集プレビューでは、画像の右下のハンドルをドラッグして幅を変えることもでき、手を離すとエディタの本文のコメントが書き換わります。

```markdown
![image.png](/attachment/6a1f…)<!--50%-->
```

閲覧画面と編集プレビューの両方で、その幅で表示されます。プラグインが無い環境や OFF のときは HTML コメントなので何も表示されず、画像は普通に表示されます。

## 依存

- GROWI 8.0.4
- [`growi-plugin-extension-hub`](https://gitea.drupal-yattemiyo.com/growi-plugins/growi-plugin-extension-hub)（ON/OFF の切り替えに必要）
  - hub が無くてもプラグイン自体は動きますが、ON/OFF を切り替えられるのは hub の設定だけです。このプラグインはメニュー項目を持ちません。

## インストール

GROWI 管理画面 → プラグイン → 新規登録で、このリポジトリの Gitea の URL を指定します。

```
https://gitea.drupal-yattemiyo.com/growi-plugins/growi-plugin-resize-picture
```

登録したら、ページを再読み込みしてください。

## 使い方

### 記法

画像の**直後**に `<!--` + 整数 + `%` + `-->` を書きます。縦横比は保たれます（高さは指定できません）。

```markdown
![image.png](/attachment/6a1f…)<!--50%-->
```

- 数値は **1〜100 の整数**です。範囲外（`0%`、`101%`）、小数（`50.5%`）、`%` が無いもの（`50`）、`%` の前に空白があるもの（`<!-- 50 % -->`）、ほかの文字を含むもの（`50% x`）は無視されます。そのときコメントはそのまま残り、画像は普通に表示されます。
- 画像とコメントの間には、同じ行のスペースとタブだけを置けます。コメントの中の前後の空白も許されます（`<!-- 50% -->`）。
- 1 つの段落に画像が複数あっても、それぞれの直後のコメントだけが効きます。
- 表示幅は、その画像を含む要素の幅（ふつうは本文の幅）に対する割合です。
- 画像をクリックすると、今までどおり原寸の拡大表示が開きます。

### 表のセルの中の画像

表のセルの中の画像では、% の基準は本文ではなく**セルの幅**です。たとえば幅 300px のセルで `<!--50%-->` と書くと、画像は 150px で表示されます。

### ドラッグで変える（編集プレビューのみ）

編集画面のプレビューで画像にマウスを乗せると、右下に小さな四角いハンドルが出ます。

- ハンドルをドラッグすると、縦横比を保ったまま大きさが変わります。画像の右上に今の % が出ます。
- % は画像を含む要素の幅に対する割合で、**5% 刻みで 5〜100%** になります。
- 手を離すと、エディタの本文が書き換わります。コメントが無ければ画像の直後に `<!--NN%-->` が足され、あれば数値が置き換わります。
- **原寸より大きくはドラッグできません。** 広げられる上限は「原寸」と「要素の幅 100%」の小さいほうです。上限が原寸のときは、% の代わりに「原寸」と表示されます。
- 上限まで広げて手を離すと、コメントが消えます（間の空白も消えます）。画像を貼ったときの書き方に戻ります。コメントが無い画像を上限までドラッグしても、何も書き換わりません。
- **Ctrl+Z で元に戻せます。** 書き換えは 1 回の編集として入るので、普通の入力と同じ扱いです。
- ドラッグを終えたときに、拡大表示は開きません。
- 手で書いたコメントが原寸より大きい場合（例: 原寸が本文の 30% の画像に `<!--80%-->`）、表示は書いたとおりです。ドラッグ中の幅は原寸が上限になり、上限＝原寸に達すると手を離したときにコメントが消えます（Ctrl+Z で戻せます）。上限に届かない位置で離したときは、その % に書き換わります。

### ON/OFF

extension-hub の設定からこのプラグインを ON/OFF できます。OFF のときは、幅が付かず、ハンドルも出ません。コメントは見えないままなので、記法は崩れません。

## 効かない場合

- **閲覧画面ではドラッグできません。** 閲覧画面では表示だけです（ページをその場で保存することになるため）。ハンドルは、ページのエディタの横にある編集プレビューにだけ出ます。古い版の閲覧（読み取り専用のエディタ）や、テンプレート・リンク編集などのモーダルのプレビューには出ません。
- **コメントが画像の直後にない。** 文章を挟んだり、次の行に書いたりすると効きません。
- **`<img>` タグで書いた画像**と、**リンクで囲んだ画像**（`[![a](u)](link)`）には対応していません。
- **ドラッグしても本文が変わらないことがあります。** プレビューは打鍵から少し遅れて描き直されるため、プレビューとエディタの内容がずれていると、安全のため何も書き換えずにあきらめます。画面には何も出ないので、少し待ってからもう一度ドラッグしてください。エディタが取得できない場合や、読み取り専用の場合も同じです。理由は extension-hub のログに出ます。
- 貼り付けた画像に `<!--NN%-->` を自動で付けることはしません。高さの指定もできません。

## 開発

```bash
npm install
npx vitest run   # テスト
npm run build    # tsc && vite build
npm run e2e      # Playwright（テスト用の GROWI が必要）
```

`dist/` はリポジトリにコミットします（GROWI がビルド済みのファイルを直接読み込むため）。
